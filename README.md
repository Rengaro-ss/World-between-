# World Between

Мод для Minecraft 1.21.1 на Fabric. Мир делят три народа — Королевство Нерис, Арки и Каменты.
Они растут, добывают ресурсы, строят и воюют сами по себе, даже когда рядом нет игрока.
Ты выживаешь между ними.

Подробности — в [docs/DESIGN.md](docs/DESIGN.md), сайт проекта — `docs/site/index.html`.

## Сборка

Нужна Java 21.

```
./gradlew build          # готовый мод: build/libs/world-between-<версия>.jar
./gradlew runClient      # запустить игру с модом
./gradlew runServer      # запустить выделенный сервер с модом
```

Положи jar в папку `mods` вместе с Fabric API 0.116.x для 1.21.1.

## Команды

- `/wb status` — состояние всех фракций
- `/wb faction neris` — подробности о фракции: склад, поселения, постройки
- `/wb chronicle [n]` — последние записи летописи
- `/wb simulate <дни>` — прокрутить историю вперёд (оператор)
- `/wb arrive <фракция>` — призвать фракцию досрочно (оператор)

Настройки: `config/worldbetween.json`.
